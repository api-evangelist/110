## 📁 ディレクトリ構造

**形式**: 箇条書きツリー形式でディレクトリ構造を表現

**記載方針**: このセクションのみディレクトリリンクを使用し、ファイルは列挙しない

**リンク形式**: ディレクトリは `/tree/` を使用
```
[{名前}](https://github.com/{OWNER}/{REPO_NAME}/tree/{BRANCH}/{相対パス})
```

**例**:
```
* [project-root/](https://github.com/{OWNER}/{REPO_NAME}/tree/{BRANCH}/) - プロジェクトルート
    * [src/](https://github.com/{OWNER}/{REPO_NAME}/tree/{BRANCH}/src/) - ソースコード
        * [components/](https://github.com/{OWNER}/{REPO_NAME}/tree/{BRANCH}/src/components/) - UIコンポーネント群
        * [utils/](https://github.com/{OWNER}/{REPO_NAME}/tree/{BRANCH}/src/utils/) - ユーティリティ関数
    * [docs/](https://github.com/{OWNER}/{REPO_NAME}/tree/{BRANCH}/docs/) - ドキュメント
```

⚠️ 各項目にはっきりとした役割説明を付けること  
⚠️ このセクションではファイルを列挙しないこと  
⚠️ このセクションではファイルリンクを記載しないこと  
⚠️ `🎯 レビュー対象ファイル候補` 以降のセクションでは、対象ファイルやコードスニペットへの GitHub リンクを必ず記載すること
