## What is and is not callable here

1→10 publishes **no HTTP API**. There is no OpenAPI, Swagger, GraphQL schema,
AsyncAPI, gRPC/Protobuf or WSDL contract on any host the company controls, no
developer portal, no API keys and no /.well-known/ discovery document. An agent
looking for an endpoint to call will not find one, and should not construct one.

The company's engagements — spatial DX solutions, location-based entertainment,
urban development, prototype development, business packages — are quoted per
project through https://www.1-10.com/contact/ and publish no rates.

## The one developer-facing product: ZIG SIM

ZIG SIM turns an iPhone or iPad into a sensor source for physical prototyping. It
publishes device telemetry to a receiver on the same local network. It is a
message publisher, not a service you call.

- Documentation: https://1-10.github.io/ZIGSIM_docs/
- Getting started: https://1-10.github.io/ZIGSIM_docs/getting-started.html
- Tutorial (motion data to a PC): https://1-10.github.io/ZIGSIM_docs/tutorial.html
- Product site: https://zig-project.com/
- Source (Pro, iOS): https://github.com/1-10/ZIGSIMPlus_iOS_Public
- Source (free, iOS, MIT): https://github.com/1-10/ZIGSIM_iOS_Public
- Receiver samples (MIT): https://github.com/1-10/zigsim-receivers

Interface shape: transport is UDP or TCP chosen in the app; message format is OSC
or JSON, also chosen in the app. OSC addresses are namespaced per device as
/(deviceUUID)/<command>; the JSON form uses dotted key paths such as accel.x,
gps.latitude, touches[i].force, arkit.position, beacon[i].rssi and
nfc[m][r].type. There is no authentication, no version negotiation, no error
envelope and no rate-limit signal. Destination is an IP address and port the user
types in — there is no base URL, and any base URL attributed to ZIG SIM is wrong.

Commands (free): Touch, Apple Pencil, Battery, Acceleration, Gravity, Gyro,
Quaternion, Compass, GPS, Pressure, Proximity, Mic Level, Remote Control, Beacon.
Commands (Pro, ¥600 one-time, iOS only): the above plus ARKit (DEVICE / FACE /
MARKER / BODY), NDI video and audio, and Image Detection. NDI, ARKit and Image
Detection cannot run simultaneously.

Standards it speaks: Open Sound Control, NDI, NDEF (for NFC payloads), iBeacon,
JSON. See conformance/110-conformance.yml.
